# 📊 Result Management System

A simple and efficient Result Management System developed to manage student records and display results easily.This project was developed as a college assignment to practically implement the core concepts of object oriented programming and result management logic.

## 📌 Overview

This system takes input of student details and their marks through user input (keyboard). The marks are stored and processed to calculate total and percentage automatically.

The program organizes the data in a structured format and displays the result in a clean and readable way, making it easy to understand each student's performance.

It ensures:

* Proper input handling of marks
* Accurate calculation of results
* Well-formatted output for better readability


## 📌 Functionality

When the program starts, it displays a simple loading interface inspired by the University of Punjab style, giving it a more realistic and professional look.

After the loading screen, the system takes input of student details and their marks through the keyboard. The marks are then processed to calculate total and percentage automatically.

All data is organized in a structured format and presented in a clean, well-aligned result display, similar to an academic result system, making it easy to understand each student's performance.
